# corpus

Εδώ ζουν τα κείμενα της νομοθεσίας, ένας φάκελος ανά νομοθέτημα, ομαδοποιημένα
κατά θεματική:

```
corpus/
├── kok/kok-5209-2025/
│   ├── full.md          ολόκληρο το κείμενο, για ανάγνωση
│   ├── articles.jsonl   μία εγγραφή ανά παράγραφο, για ανάκτηση
│   └── meta.json        προέλευση, checksum, ημερομηνία λήψης
├── adeies-odigisis/…
└── MANIFEST.json        αποτύπωμα όλων, για ανίχνευση αλλαγών
```

**Ο φάκελος είναι ακόμη άδειος.** Τα κείμενα παράγονται με:

```bash
nomothesia fetch
```

Η εντολή χρειάζεται πρόσβαση στο `et.gr`, στο `kodiko.gr` και στο
`eur-lex.europa.eu`. Αν τρέχεις μέσα σε cloud συνεδρία με περιορισμένη πολιτική
δικτύου θα αποτύχει με σαφές μήνυμα — δες το [`../docs/ENIMEROSI.md`](../docs/ENIMEROSI.md).

Τα αρχεία εδώ **παρακολουθούνται από το git επίτηδες**: έτσι κάθε αλλαγή της
νομοθεσίας εμφανίζεται ως diff και μπορείς να δεις ποια ακριβώς παράγραφος
άλλαξε και πότε.
