# Knowledge base για τον φωνητικό agent

Αυτά τα αρχεία ανεβαίνουν στο knowledge base του agent «Αίας» στο ElevenLabs.
Παράγονται με `nomothesia export` και **δεν γράφονται με το χέρι** — κάθε
αλλαγή εδώ χάνεται στην επόμενη εκτέλεση. Η πηγή είναι το `corpus/`.

## Σε τι διαφέρουν από το `corpus/`

Το `corpus/` είναι φτιαγμένο για ακρίβεια: μία εγγραφή ανά παράγραφο, με πλήρη
μεταδεδομένα, για μηχανή που κάνει ακριβή ανάκτηση. Αυτά εδώ είναι φτιαγμένα
για **φωνή**, και τρία πράγματα αλλάζουν.

**Κάθε άρθρο κουβαλά την ταυτότητά του.** Ένα σύστημα RAG κόβει το κείμενο σε
κομμάτια όπου το βρει. Αν η τομή πέσει στη μέση του άρθρου 46, το κομμάτι που
θα φτάσει στον agent πρέπει να εξακολουθεί να ξέρει από πού ήρθε — αλλιώς ο
Αίας λέει σωστά πράγματα χωρίς να μπορεί να πει πού τα βρήκε. Σε ερώτηση
νομοθεσίας, η παραπομπή είναι το μισό της απάντησης.

**Οι συντομογραφίες ανοίγουν.** Το ΦΕΚ γράφει «παρ. 2 περ. β΄ του π.δ.
237/1986». Ένα σύστημα σύνθεσης ομιλίας διαβάζει «παρ», «περ», «πι δέλτα» — ή
τα καταπίνει. Εδώ γράφεται «παράγραφος 2, περίπτωση βήτα του προεδρικού
διατάγματος 237 του 1986».

**Μόνο ισχύον δίκαιο.** Ο καταργημένος ΚΟΚ του 1999 μένει στο `corpus/` για
αναφορά αλλά δεν φτάνει ποτέ εδώ. Ένας agent που απαντά με σιγουριά, στη φωνή,
βάσει καταργημένου άρθρου δεν είναι ατελής — δίνει λάθος απάντηση.

## Πώς ανεβαίνουν

Στο ElevenLabs, στον agent → **Knowledge base** → προσθήκη εγγράφου. Δύο
τρόποι:

- **Αρχείο**: κατεβάζεις τα `.md` και τα ανεβάζεις.
- **Διεύθυνση**: δίνεις το raw URL κάθε αρχείου, π.χ.
  `https://raw.githubusercontent.com/domazakis/Nomothesia/main/export/kok/kok-5209-2025.md`

Η δεύτερη είναι προτιμότερη όταν δουλεύεις από κινητό, και έχει και ένα
πλεονέκτημα: όταν το corpus ενημερωθεί, αρκεί να ξαναδιαβαστεί η ίδια
διεύθυνση.

## Τι λείπει

Το `nomothesia export` αναφέρει στο τέλος πόσα νομοθετήματα του μητρώου δεν
βρέθηκαν στο corpus. Όσο ο αριθμός δεν είναι μηδέν, το knowledge base έχει
κενά — και ο agent θα απαντά «δεν το βρίσκω» σε ερωτήσεις που καλύπτονται από
νομοθέτημα που δεν κατέβηκε. Δες το `docs/PIGES.md` για το ποιες πηγές είναι
προβληματικές και γιατί.
