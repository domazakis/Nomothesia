# Βιβλίο σχολών οδηγών

Εδώ μπαίνει το βιβλίο θεωρητικής εκπαίδευσης υποψηφίων οδηγών.

**Τα αρχεία αυτού του φακέλου δεν ανεβαίνουν στο git.** Ο φάκελος είναι στο
`.gitignore` επειδή το βιβλίο είναι εκδοθέν έργο και προστατεύεται από
πνευματική ιδιοκτησία, ενώ αυτό το repository είναι δημόσιο. Τα νομοθετικά
κείμενα του `corpus/` είναι διαφορετική περίπτωση — δες
[`docs/PIGES.md`](../docs/PIGES.md).

Βάλε το αρχείο σου εδώ, π.χ.:

```
book/theoritiki-ekpaidefsi.pdf
```

Η επεξεργασία του βιβλίου δεν έχει υλοποιηθεί ακόμη — είναι επόμενο βήμα, μαζί
με τον agent. Όταν γίνει, θα διαβάζει από αυτόν τον φάκελο.
